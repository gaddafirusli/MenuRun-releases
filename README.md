# MenuRun

Build and run Xcode projects from the menu bar.

## Download

Get the latest `MenuRun-x.y.z.dmg` from [Releases](https://github.com/gaddafirusli/MenuRun-releases/releases/latest),
open it, and drag MenuRun to Applications. It updates itself from then on.

Requires macOS 14 or later.

---

This repository only hosts MenuRun's downloads and its update feed (`appcast.xml`).
